# SIPETIK v1.0 — Frontend

Sistem Informasi Pertanggungjawaban Teknis Kegiatan — Inspektorat Daerah Kabupaten Kutai Timur.

Frontend statis (HTML/CSS/JS vanilla) untuk GitHub Pages. Backend: Google Apps Script sebagai REST API JSON.

- Satu-satunya berkas yang perlu diedit: `js/config.js` → isi `GAS_URL` dengan URL `/exec` Apps Script.
- Panduan lengkap: `PANDUAN-INSTALASI.md`.

Modul: Dashboard · SPJ 3 tahap (identitas → rincian & potongan otomatis → generate PDF) · Daftar SPJ · Template Manager & uji render · Master Pegawai · Kode Rekening · Role & Hak Akses (RBAC) · Pengaturan · WhatsApp & Notifikasi (Fonnte + Email, blast per batch) · CRM Kontak · Ringkasan Bulanan · Realisasi Anggaran · Audit Trail berantai SHA-256 · Migrasi Data.
